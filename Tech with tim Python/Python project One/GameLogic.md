This is an personal fun learning project

The project is not being created by someone who already knows python but someone who is currently learning python and updating it a bit by bit everyday.

Its an choose your own adventure game.
The player choose an character out of the available characters. (King, Farmer, Knight, Monkey).

Now based on the user selected player we throw them with a series of questions, their answer determines their power level.

If the given answer is right user gets 10-50 points credited as per the difficulty of question.

For every wrong answer 10-30 gets deducted from the power level of the character

The game has a mega villain. If the character has enough power he can defeat the final boss else he dies.

There is no one definte path to win the game, It depends on  user choices, User can have more than enough power. Less power , get the required power by answering just 1 or 2 questions right.

The main characters of the game are King , Farmer, Knight , Monkey.
